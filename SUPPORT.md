# Getting help

- **Something broken or wrong?** Open an issue with the matching form, and include the steps and files we need to reproduce it.
- **A question about using the tool?** Read the README and `docs/` first, then open an issue with the "Question" label if it's still unclear.
- **A security problem?** See [SECURITY.md](SECURITY.md). Please don't post it publicly.

## What we can't help with here

This tracker is only for roblox-ui-renderer. These will be closed:

- help with Roblox accounts, purchases, bans or any Roblox game;
- requests to get assets, places or models you don't own, or to get around Roblox moderation or permissions;
- anything about cheats, exploits or injectors.

The maintainers work on this in their own time, so replies can take a few days.
